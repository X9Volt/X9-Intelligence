X9 Intelligence Landing Page

Overview

X9 Intelligence is a fictional AI-powered marketing assistant designed to help SaaS founders solve one of the biggest challenges in software today: distribution.

This project is a landing page built with HTML and CSS as part of my web development learning journey.

Project Goals

- Practice HTML structure and semantic elements
- Improve CSS styling skills
- Learn Flexbox for layout
- Learn positioning concepts
- Apply transitions, transforms, and animations
- Build a complete project instead of only following tutorials

Features

- Hero section
- Problem statement section
- Features section
- Call-to-action buttons
- Responsive layout
- CSS animations and transitions

What I Learned

While building this project, I improved my understanding of:

- HTML page structure
- CSS styling
- Flexbox
- Relative and absolute positioning
- CSS transitions
- CSS transforms
- CSS animations and keyframes

One important lesson was that many concepts only became clear after building and experimenting with them in a real project.

Future Improvements

- Create a working waitlist form
- Connect the project to a backend service
